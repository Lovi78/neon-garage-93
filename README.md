# Neon Garage '93

Pixel art autókereskedős tycoon, angol játékfelülettel. Jelenlegi verzió: v0.12.3 / The Art of the Deal. Dokumentáció frissítve: 2026. október 12.

A v0.12.3 fejlesztései a [codex/v0.12-art-of-the-deal](https://github.com/Lovi78/neon-garage-93/tree/codex/v0.12-art-of-the-deal) ágon találhatók. A `main` külön, v0.11.0 állapotban marad a mainbe történő jóváhagyott beolvasztásig. A legfrissebb változat letöltéséhez a GitHub branchválasztójában ezt a fejlesztői ágat válaszd.

A játék fájljai a [`neon-garage-93`](neon-garage-93/) mappában vannak. Indításhoz töltsd le a projektet, majd nyisd meg a mappában található `index.html` fájlt böngészőben. Nincs szükség telepítésre vagy szerverre.
